# Styl i kierunek wizualny

Styl aplikacji ma byc spokojny, pracowniany i intuicyjny.

Nie budujemy panelu administracyjnego z Excela. Budujemy narzedzie, ktore ma
pasowac do pracowni ceramicznej.

## Charakter

```text
cieplo
porzadek
spokoj
czytelnosc
duzo zdjec
malo zbednych instrukcji
delikatne kolory statusow
premium, ale bez nadęcia
```

## Najwazniejsza decyzja UX

Zdjecia sa najwazniejsze.

Tekst ma pomagac tylko tam, gdzie naprawde zmniejsza niepewnosc.
Jezeli cos da sie zrozumiec po kliknieciu i ukladzie, nie dopisujemy kolejnego
akapitu instrukcji.
