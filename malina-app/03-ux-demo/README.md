# UX i wersje demo

Wersja demo jest miejscem do pracy nad UX/UI.

Zasada:

```text
Nowy pomysl UX najpierw sprawdzamy w demo,
a dopiero potem przenosimy do wersji live.
```

Dlaczego:

- demo pozwala szybko klikac bez ryzyka zepsucia prawdziwych danych,
- latwiej zobaczyc, czy przeplyw jest intuicyjny,
- mozemy testowac kilka wariantow wygladu,
- nie mieszamy eksperymentu UX z logika Firebase,
- nie dokladamy kodu do live, jezeli sam pomysl nie jest jeszcze pewny.

## Dwie wersje demo

```text
Demo aktualnej wersji
  -> pokazuje to, jak dziala obecny pilot
  -> sluzy do sprawdzania, czy nic sie nie zepsulo

Demo robocza
  -> miejsce eksperymentow
  -> tu testujemy nowe widoki, slowa, kafelki, gesty i przeplywy
```

## Minimalny proces pracy

```text
1. Opisujemy pomysl
2. Robimy szkic / demo
3. Klikamy jako kursant
4. Klikamy jako instruktor
5. Sprawdzamy telefon
6. Dopiero wtedy przenosimy do live
```
